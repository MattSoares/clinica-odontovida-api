# Frontend — Clínica OdontoVida

Interface web do sistema Clínica OdontoVida, desenvolvida com React, Vite, React Router, Axios e styled-components.

A documentação completa, incluindo funcionalidades, permissões e instruções de execução, está no [README principal](../README.md).

## Executar localmente

```bash
npm install
npm run dev
```

Crie um `.env` baseado em `.env.example`:

```env
VITE_API_URL=http://localhost:3000/api
```

## Verificações

```bash
npm run lint
npm run build
```
